外 观
黑夜模式护眼；「跟随系统」会随手机的深色模式自动切换。
书架桌面背景
透明度45%
小说首页立体书展示那一屏的桌面。白天 / 黑夜各存一张，上传时存进当前外观档位。
API 连接
Key 仅保存在本机浏览器，不会上传到任何服务器。所有服务商均走 OpenAI 兼容格式。
AI 人设
封面图片
默认是空白书衣；上传后照片会自动压缩并整面铺在封面上。
本篇设定
合集模式：每章是独立短篇，设定按章生效。「＋新章节」会清空设定与对话、开始下一篇（正文保留）。
省 Token 参数
前缀 = 人设 + 本篇设定，非常稳定，只在改动时重建一次。「对话历史上限」= AI 看到的上下文长度；「正文窗口」= 续写时携带的当前章正文字数（只带本章，不串篇）。
阅读页背景
透明度35%
翻开书后的正文纸面背景，铺在文字底下。默认 35% 较淡，想明显拉高滑块。
数据管理
正文 / 封面 / 背景存 IndexedDB，其余存 localStorage，修改后自动保存。
